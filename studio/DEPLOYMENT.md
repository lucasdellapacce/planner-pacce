PACCE Studio substitui a interface anterior usando o mesmo Cloudflare Pages. Build: npm run build. Saída: .svelte-kit/cloudflare. Os arquivos antigos permanecem no histórico e nesta árvore para recuperação. Os projetos ficam em IndexedDB no navegador, isolados por origem; Baixar projeto e Importar projeto permitem transferir JSON. Nenhum projeto pessoal do Windows foi publicado. Python original é executado em WebAssembly com Pyodide 314.0.7; runtime e bibliotecas são servidos pelo próprio Pages. Não precisa túnel nem computador ligado.
